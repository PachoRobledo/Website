# Ingenio

Sitio web estático sobre inventos, inventores y curiosidades de la ciencia y la tecnología.

- `index.html`: portada (destacado, más leídos, categorías, últimos inventos, línea del tiempo, inventores, curiosidades, boletín)
- `articulo.html`: plantilla de artículo
- `styles.css`: estilos (modo claro/oscuro, adaptable a móvil)
- `script.js`: menú móvil, búsqueda, curiosidades aleatorias, boletín, botón «volver arriba»

Para verlo, abre `index.html` en el navegador. No necesita compilación.
